# Booking Platform

SaaS-платформа онлайн-бронирования времени специалистов. Multi-tenant, микросервисная
архитектура, событийная интеграция, предоплата через Stripe.

**Статус: этап проектирования завершён, реализация не начата.**

## Ключевые ограничения проекта

- Один разработчик. Цель — production-grade практики, не объём функциональности.
- Домен минимальный и безупречный; платформа (observability, CI/CD, k8s) — полная.
- Развёртывание локальное (kind/k3d), GitOps через ArgoCD.

## Состав сервисов

| Сервис | Ответственность |
|---|---|
| `identity` | пользователи, OAuth, JWT, RBAC |
| `catalog` | организации, специалисты, услуги, цены |
| `booking` | расписание, доступность, брони, оркестрация саги |
| `payment` | Stripe, авторизация/списание/возврат |
| `notification` | доставка уведомлений (email реальный, SMS/push — адаптеры-заглушки) |
