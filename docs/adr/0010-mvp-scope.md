# ADR-0010: Границы MVP

- **Статус:** Принято
- **Решения:** D5

## Контекст

Заявленный объём (повторяющиеся записи, отзывы и рейтинги, чёрные списки, хранение
сертификатов, три канала уведомлений, полная инфраструктура) недостижим для одного
разработчика в разумный срок. Цель проекта — production-grade инженерные практики,
а не ширина функциональности.

Бюджет один и делится между глубиной домена и полнотой платформы.

## Решение

**Домен минимальный и безупречный, платформа полная.**

Входит в MVP:

- регистрация, вход, OAuth Google, JWT с ротацией refresh, RBAC по тенантам;
- организации, специалисты, услуги (длительность, буфер, цена);
- рабочие часы, исключения (отпуск, разовый выходной, дополнительная смена);
- расчёт свободных слотов, создание, отмена, перенос брони;
- предоплата через Stripe с сагой и компенсацией;
- уведомления: email реальный, SMS и push — адаптеры-заглушки за общим интерфейсом;
- полная платформа: OpenTelemetry, метрики, логи, трейсы, алерты, CI/CD, Kubernetes.

Сознательно не входит:

| Не входит | Причина |
|---|---|
| Повторяющиеся записи (RRULE) | Отдельный проект: серии, исключения из серии, перенос одного вхождения, DST внутри серии |
| Отзывы и рейтинги | Изолированный сервис, ничего не добавляет к целям обучения |
| Чёрные списки клиентов | Расширение вширь, простое CRUD-правило |
| Загрузка сертификатов и фото в S3 | Инфраструктурно тривиально, доменно бесполезно |
| Поиск специалистов по геолокации | Полноценная поисковая задача, отдельный масштаб работ |
| Мультивалютность | Одна валюта на организацию |
| Штрафные политики отмены | Усложняет сагу без новых паттернов |
| Stripe Connect и выплаты организациям | KYC, отчётность, недели работы; деньги остаются на аккаунте платформы |
| Гостевое бронирование | Клиент всегда зарегистрирован |

## Рассмотренные альтернативы

**Реализовать заявленный объём целиком.** Отвергнуто: не завершается одним человеком;
результат — набор недописанных сервисов вместо работающей системы.

**Богатый домен, урезанная платформа.** Отвергнуто: прямо противоречит цели проекта.

**Универсальный конфигурируемый домен под любой тип специалистов.** Отвергнуто:
выбрана одна модель — услуга фиксированной длительности с буфером, расширяемость
заложена в схеме, но не реализована.

## Последствия

**Приобретаем:** достижимый объём; каждая реализованная часть доведена до
production-качества.

**Платим:** продукт неполон с точки зрения рынка; часть исключённого (особенно
повторяющиеся записи) при последующем добавлении потребует изменения модели данных
броней, а не только новых таблиц.
